# Prehistoric AR – reconstructed source

The original APK (package `com.ronaldlazaga.prehistoricAR`, v1.0) was generated by a
"web to app" builder. It is a WebView wrapper that loads https://asblr.com/kJxCRzO.
This project rebuilds that app from the APK's manifest, config (`assets/app_settings.json`),
icon/splash images and class structure, and adds a **`</>` View source** button.

Open the folder in Android Studio (Hedgehog or newer), let Gradle sync, then Run.
The AR / 3D content itself lives on the website, not in the app.
